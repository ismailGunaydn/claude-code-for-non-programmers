# Claude Code for Non-Programmers: Companion Templates

Copy-and-use files for the book **Claude Code for Non-Programmers (2027 Edition): A Business Owner's Guide to Building Your Own AI Operating System** by İsmail Günaydın.

Every template here comes from a system that runs a real small business: websites, a lighting-decoration company, and a book production line. Names, numbers, keys and anything that could identify a person or an account have been removed.

No email sign-up. No paywall. Take what you need.

## How this repo is organized

The folders follow the parts of the book.

| Folder | Book part |
|---|---|
| `01-foundations` | Part 1. Foundations |
| `02-memory-and-identity` | Part 2. Memory and Identity |
| `03-skills-and-commands` | Part 3. Skills and Commands |
| `04-agents` | Part 4. A Team of Agents |
| `05-automation` | Part 5. Automation |
| `06-connecting-the-world` | Part 6. Connecting the World |
| `07-business-systems` | Part 7. Real Business Systems |
| `08-safety` | Part 8. Safety and Failure |
| `09-your-operating-system` | Part 9. Your Operating System |

## Before you copy anything

1. Read the matching chapter first. A template without its "why" is easy to misuse.
2. Never paste passwords, API keys or tokens into these files. See [SECURITY.md](SECURITY.md).
3. Claude Code changes often. Check [CHANGELOG.md](CHANGELOG.md) and the official documentation when something behaves differently.
