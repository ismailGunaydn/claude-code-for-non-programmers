# SEO Lessons (load first)

## Before anything else
1. Read references/red-lines.md. Never break one.
2. Read references/dont-do.md. If a plan includes
   anything on that list, remove it and say why.
3. Measure in built or live pages. Never report a
   count from source files or a web summary.

## For an impression drop
Follow this order and report which step found it:
screenshot, hidden sections in raw HTML, my deploys,
site moves, algorithm last.

## Report format
| Finding | Page or file | Real count | How measured |
End with: "Not checked:" and list what you skipped.

## Never
- Never change, deploy or delete anything in an audit.
- Never blame an algorithm before steps 1-4 are done.
