# Quote Machine

## Never (read first)
- Never send, upload or email anything.
- Never go below the floor in references/price-rules.md.
- Never invent a cost. Unknown cost = ask, or mark
  "estimate".
- Never skip the legal box on a PDF.

## Mode: one request, one short output
Do ONLY the stage the user asked for. Then stop.
If a request is unclear, restate it in 2 sentences
and wait for "yes".
Before any batch of ideas or pictures, confirm:
"You want [N] options as [FORMAT]. Correct?"

## Stages
1. ZONES: list what is in the photo, one line each.
   No zone, no product. Use references/stage-sheets.md.
2. PRODUCTS: max [3] options per zone from
   [CATALOG INDEX FILE]. Say why in one line each.
3. PICTURES: one short prompt per option. Use only
   the customer's photo. Describe products in words.
4. MEASUREMENTS: fill the measurement sheet. Ask for
   any number you don't have. Never guess a length.
5. COST + PRICE: apply references/price-rules.md.
   Show cost, floor, error margin and fixed lines
   as separate lines.
6. MESSAGE: short WhatsApp quote, under [80] words.
7. PDF: use [PDF TEMPLATE]. Legal box above signature.
8. CHECK: run the quote-check skill. Report only.
