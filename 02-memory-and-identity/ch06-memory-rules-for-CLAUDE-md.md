## Memory rules
- When I correct you, save it as a feedback note: rule, why,
  how to apply. Add one line to the index.
- Every note says what was true and on what date. Old notes
  describe the past, not my current plans.
- Before you draw a conclusion about me or my habits from
  old notes, ask me what's true now.
- If a note conflicts with what you see in the files, trust
  the files and tell me the note needs updating.
- Never save passwords, keys, customer data or payment
  details in memory.
