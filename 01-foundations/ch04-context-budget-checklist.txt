[ ] I ran /context. Window already used before I typed: ______

DURING THE SESSION

[ ] Huge file? I asked Claude to read it in parts

[ ] Before a summary, I used: /compact keep <what matters>
[ ] Long job? Progress file is updated after every batch

WHEN SOMETHING FEELS OFF

[ ] "Context limit reached" -> /compact with a focus, or /clear
[ ] "Thrashing" error -> stop loading the big file whole
[ ] Usage climbing fast -> /usage, then /clear between tasks
